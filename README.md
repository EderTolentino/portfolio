# Web Development Portfolio — Eder Tolentino

This React portfolio documents projects built during and after my UPSkill training, including frontend exercises, full-stack applications and personal language-learning tools.

**Portfolio:** https://portfolio-nine-psi-37.vercel.app/

## Featured projects

- [UPTube](https://github.com/EderTolentino/web-uptube) — React and Node.js video-sharing project. Source code is available; deployment is not guaranteed.
- [UPBNB](https://github.com/EderTolentino/UPSkill_React-UPBNB) — React accommodation-booking project.
- [JavaScript Games](https://github.com/EderTolentino/UPSkill_JavaScript-Jogos) — browser-based games.
- [Test Conjugaison](https://github.com/EderTolentino/MyProjects_Test-Conjugaison) — French verb-conjugation practice.
- [Les Paroles](https://github.com/EderTolentino/MyProjects_Les-Paroles) — language learning through song lyrics, built with PHP, JavaScript and database integration.
- [Poliglota](https://github.com/EderTolentino/MyProjects_Poliglota) — multilingual vocabulary practice using PHP, JavaScript, AJAX and a database.

## Project availability

Some older course exercises have been made private. Their screenshots and descriptions may remain in this portfolio as a record of the learning journey, but they no longer link to private repositories or inactive demonstrations.

Projects requiring PHP and a database are linked to their source repositories rather than presented as working online demos.

## Local development

```bash
npm install
npm start
```

To generate a production build:

```bash
npm run build
```

## Deployment

This repository contains the source for the existing Vercel website. Changes pushed to GitHub are not necessarily visible online until a new production deployment succeeds.

## Context

This site represents an earlier web-development stage of my career. It is retained as a project archive and demonstration of hands-on development experience.
